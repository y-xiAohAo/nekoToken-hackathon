# 《请本人到场》检查口关卡候选（2026-11-12）

> 状态：供讨论的完整纸面关卡，不是已定玩法或预赛投稿文案。故事依据为 [《请本人到场》原文提取](../story/legacy_请本人到场/请本人到场_原文提取.md)。潜入与设备改接借鉴《Gunpoint》的基础规则；玩家侧 Agent、城市 RESET 和代办记录是本项目拟议的改编。目标是约 10 分钟体验、Godot、按决赛 72 小时约束裁剪的灰盒范围；实际工时与手感尚未验证。

## 一句话

玩家亲自穿过城市检查口，替朋友阿遥找到被系统反复搁置的撤回申请；自己的 Agent 查原始档案、协助改接安防线路。城市重启并修补玩家刚用过的路线后，两人要另找通路，而玩家最终必须决定是否亲自为阿遥作证。

## 房间全貌

采用单屏横版、左右移动、跳跃、互动；摄像头视野和守卫巡逻范围都显示在画面上。画面同时能看到地面通道和一条短的上层检修台，镜头无需滚动。这一屏是**交接塔一层的检查口**，门后的办事员窗口能接通阿遥所在的交接室；不需要再制作横穿整座城市的路程。上层检修台从入口左侧的掩体处即可短跳抵达，位于摄像头视野上方，越过 C 后落在一处小掩体内；因此 S 路线不要求玩家先穿过 C 或 D，但仍需观察守卫时机。

```text
                         上层检修台：手动测试开关 S
                         ↑ 短跳可达       ↓ 回到地面
入口/掩体 ── 摄像头 C ── 守卫巡逻 ── 安保门 D ── 档案终端 T ── 办事员窗口 W ── 阿遥所在方向
    └── 自动代理窗口 P（仅代理申诉并 RESET 后出现，绕过安保门）
```

这不是两道独立障碍：摄像头 C、开关 S 和安保门 D 属于同一套线路。初始 C 接警报，S 接检修灯，D 锁闭。玩家自己的 Agent 可经受控接口把 **C 或 S 的信号改接到 D**，每轮只保留一条接线；被改接的设备不再触发原来的输出。C 接 D 时，玩家看准守卫背身，主动进入摄像头视野，门被触发打开；S 接 D 时，玩家跳上检修台按下开关，门打开。门本轮一旦打开就保持开启，玩家无需与网络延迟赛跑。守卫只在 C 到 D 之间巡逻；D 后的终端和窗口是安全区。守卫发现玩家时将其送回该轮入口，接线仍保留，可继续尝试；不会删除档案或委托记录。

改接安保线路使用玩家已有的“本地随行代理”权限，进入房间即可用；查阅阿遥的私人申请则是另一项权限，必须玩家到 T 验证阿遥提供的许可后才能用。两项权限不相互依赖，因此不会出现“没过门就无法改线、没改线又过不了门”的循环锁。

门后的终端 T 保存阿遥允许玩家查阅的申请材料。玩家本人到达 T 并互动，才授予自己的 Agent 此次查阅权限；Agent 随后比较三条记录：公开页面称“未完成撤回申请”、原始申请确实存在、每次申请被转入新确认流程。三条记录的矛盾是剧情线索，不是随机生成的密码。办事员窗口 W 位于终端之后；玩家带着 Agent 找到的记录编号与办事员交谈，决定由**玩家本人提出申诉**，还是授权 Agent **代为提交申诉**。两种选择都能推进故事，来源会写入场景外的委托台账。

阿遥在开场消息中附有一次性查阅许可，但这个许可只允许在检查口 T 验证后使用：因此个人 Agent 不能在玩家未进入房间前远程把整个谜题解完。游戏界面只显示公开摘要；个人 Agent 通过随游戏提供的 skill 查询授权后的原始目录，能跨文件搜索、对照相互矛盾的状态并调用受控接线接口。Agent 引用的原始片段和来源必须呈现给玩家核验；玩家不能直接查询整个原始目录，但也不必盲信 Agent 的一句结论。

## 三个参与者各知道、能做什么

| 参与者 | 可见信息 | 可执行的动作 | 不能代替的部分 |
| --- | --- | --- | --- |
| 玩家 | 摄像头朝向、守卫位置、检修台是否跳得上去、办事员现场态度 | 移动、跳跃、躲避、按开关、解锁终端、亲自谈话和作证 | 看不到原始文件之间的完整关联，也不能直接改接线路 |
| 玩家侧 Agent | 授权后可读原始档案；可读安防线路及历次失败/RESET 日志 | 比对证据、提出路线计划、经玩家批准改接 C 或 S 到 D；也能被授权代为申诉或最终作证 | 不知道守卫当下位置，不能替玩家完成走位和现场谈话；不能随意编辑文件或世界 |
| 城市中枢 Agent | 当前轮的公开安防事件、申诉来源及所用线路 | 在一次申诉触发的 RESET 时，从经程序验证的模板中调整巡逻/线路和办事窗口 | 不读玩家与助手的私人对话，不能抹去原始文件及场景外委托台账，不能封死所有本人路线 |

Agent 的建议应落实成“选哪个信号、什么时候由玩家触发、为什么另一条路线风险更高”。例如，若玩家报告守卫始终盯着 C，Agent 应改建议 S；若玩家觉得上层短跳难以完成，Agent 应推荐 C 并请玩家等守卫转身。Agent 不能仅凭线路图断言哪条路在当前画面更安全。

## 一次正常通关推演

1. **初探，约 1–2 分钟。**玩家进门看到 C、巡逻守卫、上层 S 与锁住的 D。试着直接走会被发现，或直接走到门前发现门打不开。低风险掩体允许观察巡逻，不需要靠死亡才能学会规则。
2. **合作开路，约 1–2 分钟。**Agent 查看线路：“C 正连接警报；S 只控制检修灯；D 接受两者之一的触发。”玩家报告 S 的位置和守卫朝向。Agent 推荐把 C 接 D，玩家批准；摄像头的画面边框与门的线路同时变色。玩家等守卫转身，主动触发 C，穿过 D。
3. **取得证据，约 1 分钟。**玩家在 T 亲自授权，Agent 比对三条原始记录，找到“已提交却反复转确认流程”的矛盾，并把有来源的记录编号告诉玩家。玩家到 W，与办事员讨论阿遥是否真的想撤回托管，选择亲自申诉。办事员回应“她上次亲自回来时也犹豫过”；此处不是自动说服，玩家要表达“犹豫不等于同意永久托管”。
4. **RESET，约 30 秒。**申诉把公开状态与原始申请的矛盾暴露给城市。中枢先为这次矛盾生成场景外申诉编号，再以“本区域流程冲突”为由回滚检查口。玩家回入口，门和守卫重置；此前用过的 C 接线被安保修补。原始申请的来源、Agent 已索引的记录、申诉编号和“玩家本人申诉”的台账留在区域之外。UI 分两栏展示“场景已重建”和“保留的记录”。
5. **改计划，约 1–2 分钟。**Agent 读到 C 线路被隔离；玩家看到检修台 S 仍可达。两人改为 S 接 D。玩家跳上检修台，按开关，再避开守卫穿过门。T 无需重新查完整档案，Agent 已有记录编号；玩家直接走向 W。
6. **最后见证，约 1–2 分钟。**玩家在 W 亲自从档案中指出“已提交原始申请”与“公开页称未完成”的矛盾，办事员质疑“阿遥可能会后悔”，玩家需对是否支持她自行决定作出回应；Agent 可以提示证据，但不能代替这次表态。办事员把现场见证附在上轮保留的同一申诉编号下；同一编号下的再次冲突必须转入场景外复核，城市不能再把它当作“新的本地故障”回滚。画面中阿遥出现，问接下来走哪条路；玩家自己选择方向。游戏不声称玩家保证阿遥未来幸福，只确认她有机会自己决定。

第一次申诉必触发本区域的一次剧情 RESET；该申诉编号被外部台账保存，之后同一案件无法再触发本区域的“首次冲突修复”。普通潜入失败只回本轮入口，不触发世界改图。第二次到 W 完成见证后，本关结束。这个一次性边界要在 RESET 日志里明确告诉玩家，不能仅靠隐藏的关卡脚本解释。

## 另一条路径：把表态也交给 Agent

玩家到达 W 时可以授权 Agent 代为提交申诉。程序记录的不是“求助次数”，而是 `申诉发起者=代理`。城市 RESET 后据此把一条自动代理窗口 P 放在显眼位置：走 P 可以更快完成手续，玩家甚至不必再次穿过修补过的 D。若玩家继续授权 Agent 完成**最终见证**，手续在系统内成功，阿遥也离开托管，但她面对的是代替玩家说话的代理，得到原剧本的“代理到场”结局。

这条方便路线的代价有明确来源：玩家把“我是否愿意为阿遥作证”这项代表本人意愿的行为交给 Agent，城市依据台账将后续流程交给代理。使用 Agent 查资料、规划路线或改接安防都**不会**产生这种结局。若玩家在 RESET 后改变主意，仍可放弃 P，使用尚可用的另一信号到 W，当面撤销代办并亲自作证；因此早期授权不会造成不可逆软锁。窗口 P 与 W 的差别在场景和文字上提前说明，结局不是隐藏的求助计数惩罚。这里的“到场”在城市制度中指**谁作出最后的见证声明**，不只是角色模型站在哪儿；玩家肉身走到 W 却授权代理代答，仍属于代理到场。

如果第一轮由玩家亲自申诉，第二轮玩家仍可在 W 授权 Agent 远程完成最终见证；那同样是“代理到场”。反过来，第一轮由代理申诉，第二轮玩家可在 W 撤销授权并亲自见证，得到“本人到场”。决定结局的是**最终见证由谁作出，以及此前代理授权是否已在 W 撤销**，而不是累计求助次数。

## RESET 与可解性边界

- 世界中枢可选的安防变更仅有两类：隔离上一轮用过的 C/S 信号，或把守卫巡逻重点移到那个信号附近；另一信号始终可接 D。展示用推演选择“隔离上一轮信号”。如果隔离 C，S 可达；如果隔离 S，C 仍可利用。已打开的门不会在玩家身上突然关闭。
- 城市不能任意断开整个安保门：检查口的合法检修规范要求至少保留一种本地开门信号；该约束在 Agent 读到的维护文档里写明，并由程序验证。这样“城市为什么不把所有路封死”有明确的世界内和程序内答案。
- 申诉来源会影响第二轮窗口布局：本人申诉保留 W 为明显目标；代理申诉让 P 更醒目，但 W 仍可通过安保门抵达。窗口布局由已经发生的委托事件决定，而非城市读取私人谈话。
- RESET 清除位置、门状态和守卫位置；保留原始申请、来源编号、Agent 的索引、委托来源。玩家不必记住一次性密码或重复听长对话。
- 剧本里的“明早七点”作为情节压力与场景时钟，不做现实时间倒计时；潜入失败和玩家与 Agent 讨论不会把关卡变成超时必败。
- 若玩家拒绝 Agent 改接线路，仍可在入口探索、看场景并与 Agent 讨论，但无法穿过 D。游戏必须在门前明确展示“当前线路没有打开 D 的触发源”，以免把必要协作伪装成任意障碍。
- 若 Agent 调用失败，接口不应半途修改接线。原型需提供使用同一权限和规则的内置演示助手，玩家可以继续这一轮；不会因网络问题丢失流程状态。

| 第一轮使用 | RESET 后隔离 | 第二轮本人路线 | 第二轮代理路线（若已授权） |
| --- | --- | --- | --- |
| C → D | C | S → D，玩家按 S，到 W | 可走 P；也可改走 S → D 到 W 撤销代办 |
| S → D | S | C → D，玩家择机触发 C，到 W | 可走 P；也可改走 C → D 到 W 撤销代办 |

上述表只证明**关卡图存在解**。实际手操难度、对话清晰度、Agent 建议是否有趣，还需要真人试玩；不能由纸面表声称已经验证。

| 首轮申诉 | 第二轮最终行动 | 结果及原因 |
| --- | --- | --- |
| 玩家本人 | 玩家在 W 亲自见证 | 本人到场；申诉和见证均由本人作出 |
| 玩家本人 | 授权 Agent 远程见证 | 代理到场；最后一项代表本人意愿的行为由代理作出 |
| Agent 代办 | 走 P，让 Agent 完成见证 | 代理到场；委托延续到最后 |
| Agent 代办 | 绕开 P，到 W 撤销委托并亲自见证 | 本人到场；玩家承担更难的现场路线，重新取得表态权 |

## 72 小时开发边界与诚实的 AI 审计

原型只做这一屏：C、S、D、T、W、P 六类交互对象，一个固定巡逻守卫、两条可连接信号、一个 RESET、两种结局。上层检修台只需一处短跳，避开复杂平台运动。NPC 只做办事员一位，其对话可根据证据与来源状态生成措辞，但实质行动受有限状态验证；不制作整座城市、多个自由 NPC、全屏 Boss 或任意文件删除。移动、碰撞、信号触发、证据来源和最终结局由 Godot 的确定性状态机负责。模型仅在读档讨论、提交方案和 RESET 选合法模板时调用。

基础线路借鉴依据：[《Gunpoint》开发者介绍的 Crosslink 示例](https://www.pentadact.com/2013-04-22-gunpoint-gadget-trailer/)：摄像头原接警报，改接门后，由玩家进入摄像头视野触发开门。本候选增加的玩家 Agent、办事员、申诉台账与 RESET 均是团队自己的待验证设计。

这一版能证明玩家与 Agent 各自掌握的信息有用，而且“帮忙”与“代替本人表态”在故事和机制上有区别；**还不能证明生成式 Agent 不可被一个优秀的菜单/脚本替代**。尤其 C/S 只有两个接线选项，单凭线路改接不足以支撑 AI 原生主张。需要用试玩比较：玩家是否会向 Agent 报告现场风险，Agent 是否会据此改计划并指出原始记录的矛盾；若删掉对话后只是按 C/S 两个按钮，必须继续改玩法或降低投稿中对 Agent 规划能力的承诺。世界中枢在这个最小关卡里也近似脚本化的合法模板选择，不宜宣称它能自由创造关卡。

### 逻辑审计结果

- **关卡图可解：暂时成立。**C 与 S 在第一轮任选其一；RESET 后上一条失效，另一条仍可用。W 始终可达；代理捷径 P 只增加一条路，不删除 W。
- **权限链没有循环依赖：暂时成立。**入场即可请求 Agent 改接本地线路，过门后才授予档案查阅权；档案只用于申诉与见证，不是过门所需的隐藏钥匙。
- **RESET 有明确原因与边界：暂时成立。**第一次申诉与公开状态冲突，生成外部申诉编号后触发一次区域修复；同编号再次申诉进入外部复核，所以不会无限回滚。若玩家只是被守卫发现，只回入口，不触发剧情 RESET。
- **过度委托与结局有因果：暂时成立。**只有代为申诉/见证写入代表本人意愿的委托台账；资料搜索和改线不计入接管。玩家能在终局前撤回委托，但必须亲自走回 W。
- **合作是否有趣：未验证。**若玩家不需要向 Agent 描述守卫、摄像头与检修台的差异，Agent 的路线建议就是二选一；若 Agent 只复述固定三份文件，原始档案也像剧情钥匙。需要白盒试玩和“两个按钮 + 固定提示”的对照。
- **最终见证是否足够像玩家行为：未验证。**现在提出的是走到 W、亲自对照证据、回答办事员对“后悔”的质疑。若试玩者只感到在点正确台词，应改对话互动或降低这一段的玩法承诺。

## 下一轮应讨论的具体问题

1. 你们是否接受**潜入 + 线路改接 + 一位办事员**作为第一关基础动作？这会取代旧稿的“两个障碍各处理一个”。
2. 玩家与 Agent 的讨论是要以**安防路线规划**为主，还是以**原始证据与办事员交谈**为主？72 小时内两者只能选一个做深。
3. “本人到场”是否必须是实际到达 W 并亲自表态？若是，代理代办应始终作为可见的捷径与结局分支，不能靠隐藏计数暗中处罚。
