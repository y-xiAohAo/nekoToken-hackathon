# 协定室：具体玩法基准候选（2026-11-11）

> 纸面白盒，供团队讨论。Godot 单屏 2D 横版；10 分钟体验目标；不是已提交的预赛方案。

## 一句话玩法

玩家要穿过一个有两条路线的测试室。起点的门由世界 Agent 控制；玩家侧 Agent 可以代表玩家签订一份「开门协定」，代价是本轮暂时失去一项操作能力。玩家必须告诉自己的 Agent 现场哪条路需要什么操作，决定接受哪项代价，然后亲自通过。第一次到出口必定 RESET；世界 Agent 观察玩家刚才的通关方式后改变一条路线。旧协定若不修订，就可能挡住下一次通关。

## 单屏白盒布局

```text
                     上路：一个只能靠【跳跃】通过的缺口
                    ╱                           ╲
起点 ── 协定门 ── 分岔                             ── 出口
                    ╲                           ╱
                     下路：一个只能靠【冲刺】穿过的短时通道
```

玩家初始拥有「跳跃」与「冲刺」；两条路线各自独立通往出口，不能在中途切换。协定门关闭时无法前进。路线在同一屏内，不用滚屏；动作难度定为新手能在 1–2 次尝试内完成。

## 精确规则

1. **玩家可做**：观察两条路线；移动、跳跃、冲刺；随时与个人 Agent 对话；在起点/RESET 阶段批准或拒绝 Agent 提议的协定。玩家不能直接操作协定门或编辑路线。
2. **玩家侧 Agent 可读**：前几轮的死亡原因、路线选择、已经签过的协定，以及世界 Agent 公开提出的协定条款。它不能直接读取玩家屏幕上当前的路线变化；需向玩家询问。
3. **玩家侧 Agent 可做**：向世界 Agent 提交一份持续生效的协定，内容为「每次从起点出发时开门；本轮禁用跳跃」或「每次从起点出发时开门；本轮禁用冲刺」。它可根据玩家描述提出理由、备选路线并追问遗漏信息；首次提交和每次修订都必须由玩家确认。任一时刻只有一份协定登记；玩家可在起点暂停它、请 Agent 修订，或保持原样出发。离开起点后本轮不能改约。
4. **世界 Agent 可做**：只在玩家**第一次抵达出口后的 RESET**，依据刚才实际走过的路线，将该路线封闭；另一条必须保持可通行。变更在玩家再次出发前显示。它不能在玩家跑到一半时改地形，也不能修改协定条款。此模型里的“编辑关卡”就是合法选择路线开闭状态；这一固定反应暂时不能证明世界 Agent 的智能价值。
5. **RESET**：第一次到出口，获得一份跨轮保留的“通关证明”，立即 RESET 回起点。世界 Agent 封闭上一轮路线；门重新关闭。协定保持登记，但能力禁用随 RESET 结束，到下一次出发时才重新生效。玩家可先观察新场景、与 Agent 商量并修订，也可沿用原协定出发。第二次到出口，获胜。
6. **失败**：落入缺口、短时通道夹住角色，或玩家选择重新开始，都会 RESET 回起点；死亡 RESET 不触发世界改图。通关证明和已登记协定保留，能力禁用暂时解除，直到再次出发。任何世界配置下，至少有一条路线能在合适协定下通过。

## 具体推演

| 时刻 | 对话、行动与世界变化 | 为什么成立 |
| --- | --- | --- |
| 第一轮 | 玩家看到上路要跳、下路要冲刺，告诉助手“我比较擅长跳，不想跑计时”。助手提议签「开门，禁用冲刺」，玩家确认后亲自跳过上路到出口。 | 协定不是无条件开门：它强制玩家放弃一项操作；哪项代价合适取决于玩家看到的路线及自身偏好。 |
| 第一次成功后 RESET | 通关证明保留；世界 Agent 看到玩家靠跳跃通关，合法封闭上路，并展示上路被封的变化。 | 世界的反制有来源、时点和界限；下路仍可通关。 |
| 盲目沿用旧协定 | 玩家看到 RESET 后仍选择让登记中的「禁用冲刺」协定自动生效，门打开了，但上路已封，下路又必须冲刺。玩家卡住，可主动 RESET 并改约。 | 障碍来自未核对当前路线就沿用旧协定；不是咨询次数惩罚。旧协定在原世界曾经正确。 |
| 合作修订 | 玩家告诉助手“上路被封了，只剩冲刺通道”。助手解释旧约为何失效，改提「开门，禁用跳跃」。玩家确认并亲自跑过下路，到出口获胜。 | 玩家给出当前现场；Agent 管理规则协定并修订计划。双方缺一不可。 |

如果玩家第一轮走下路，世界 Agent 可封闭下路；第二轮便需要改约走上路。玩家也可在第一轮主动试另一条路，世界 Agent 的选择根据实际行动而非读私聊。

## 两个 Agent 与玩家各自的边界

- 玩家侧 Agent 负责把玩家的能力偏好和现场描述转成一份有后果的协定；它不能代替玩家跑跳，也不能看到当前关卡的全部细节。
- 世界 Agent 负责在 RESET 时从合法编辑中选择一项；它能看到玩家实际行为与已签条款，不能看私人对话。
- 玩家负责亲自观察、操作、批准条款，并在世界改变后告诉助手必要的新事实。

## 诚实的设计风险

1. **菜单替代风险**：仅有两种协定时，固定选项菜单也能表达全部有效动作。初版可以验证“能力交易 + RESET + 玩家/助手交流”是否有趣，却还不能证明生成式 Agent 不可替代。若此底座可玩，下一步应加入少量有代价的条件条款，让助手依据自然语言偏好和现场描述主动提出非固定组合；不能靠增加聊天台词掩盖此问题。
2. **世界 Agent 脚本风险**：若它永远封上一轮的路线，同样可由脚本实现。先验证这条反制是否公平、易懂；若成立，再让它从 2–3 种合法变化中依据玩家行为选择，不承诺自由生成地图。
3. **操作手感风险**：跳跃缺口与短时冲刺通道必须先做灰盒测量；若任一路线难到需要反复练习，会抢走对话规划与 RESET 的演示时间。
4. **剧情包装风险**：“通关证明”只用于解释首次抵达出口为何强制 RESET；如果试玩者觉得牵强，应改用两阶段目标展示，而不是加长设定对白。

## 10 分钟纸面节奏与最小范围

第 0–1 分钟认识门、两条路线和“能力交易”；第 1–4 分钟交流并完成第一次穿越；第 4–5 分钟看到 RESET 和世界 Agent 的改动；第 5–8 分钟决定沿用或改约，亲自完成第二次穿越；第 8–10 分钟用于一次失败修正及结局反馈。实际时长需试玩测量。

Godot 只需一屏、两条路线、两种能力禁用、一个协定门、两个世界合法编辑选项、RESET 计数与结构化事件记录。玩家侧 Agent skill 提供 `read_history`、`read_contracts`、`propose_contract` 三类受控接口；内置演示助手复用同一接口。程序验证路线始终可通，模型调用只在对话、RESET 与协定提交时发生。

## 2026-11-11 纸面审计：暂不把这一版写成定案

| 情况 | 纸面结果 | 判断 |
| --- | --- | --- |
| 初始上路跳跃，协定禁用冲刺 | 上路可通，取得第一份证明后 RESET | 有解。 |
| 初始下路冲刺，协定禁用跳跃 | 下路可通，取得第一份证明后 RESET | 有解。 |
| 世界封闭上轮路线，玩家看见变化并改签另一项协定 | 剩余路线仍可通；第二次抵达出口获胜 | RESET 后有清楚的新决策。 |
| 死亡后 RESET | 地图保持原样，玩家回起点，可重新讨论协定 | 失败后能学习并重试，世界不会频繁改图。 |
| 玩家沿用持续登记的旧协定 | 玩家可能卡在新路线前，但可主动 RESET 并修订 | 代价来自玩家选择沿用已过期的委托；助手无须故意装傻。不过若玩家总能在起点轻易看出正确选项，协定仍会退化成菜单。 |

这一版验证了**能力交换、手操、世界变更和 RESET 的基本闭环**，尚未验证玩家侧 Agent 是否真正会制定策略。两项协定可以用菜单替代；世界若总封上一轮路线，也可以用固定脚本替代。下一轮讨论应决定：保留此关卡作为低成本原型，还是把 Agent 专属动作升级为可审查、可持续生效的条件策略。任何升级都要先给出一张可纸面试玩的关卡图和至少两轮推演，再改正式预赛方案。
