# 世界观一致性与可玩章节插入点评估

更新：2026-11-26。依据[2026 年新片段](游戏背景——2026ai.docx)、[2026—2042 长篇](背景故事v2_2026至2042.md)与用户最新确认：海普＝父亲，贾斯珀＝叔叔。本文只评估文本之间和[现行玩法](../../PRELIMINARY_DESIGN_SPEC.md)之间的关系；提议不等于新正史。

本轮已确认：姓名沿用贾斯珀；四轮重启、局部回退与双方记忆全部保留，必须有世界内解释，接受新增推演／模拟；允许更换电机与维修的含义，保留到场操作、停留、产生真实报告、撤离；首章成功取得妹妹接收地点与下一步联络线索。最新要求是尽量保留玩法框架，让剧情自然贴合。下文具体模拟身份、权限与装置均为候选，不将讨论中的新增设置当作原文事实。

## 文本一致性

**没有发现必须推翻两份原文才能解决的年代或亲属关系冲突。**按长篇按年份计算的年龄，海普在 2026 年约 24 岁，贾斯珀约 23 岁；前者工作、后者实习与此相容。2026 年长篇写哥哥出生，兄弟见面片段未提及孩子，属于叙述省略。卡尔在 2026 年希望考尔德率先做出 AGI，不等于他已在 2036 年取得成果；长篇写梁知远组织团队完成复核，两件事可以并存。

## 与玩法的实质断点

1. **转送已经完成。**长篇明确写车辆通过交接通道，哥哥随后才到康复站；若仍让玩家在站里“赶上并阻止转送”，就与原文冲突。游戏的第一关应是追索路线或下一个可核实线索。
2. **检查区、电机与出口缺少因果。**哥哥会修设备有文本依据，但长篇没有写“必须修电机才能追人”。目前的检查区四区地图也不是原文地点，只能作为新设计的关卡空间。
3. **个人助手的设备权限尚无来源。**HSF 地区使用 AI 服务，不等于一个 16 岁少年的 Agent 可控制联合体摄像头和照明。联络点、权限来源和少量改动上限须有世界内解释。
4. **城市系统身份和信息边界尚未锁定。**联合体承包康复站诊疗翼和专用转运通道，但“城市系统 Agent”与联合体的隶属关系、它为何定位哥哥尚未写明。玩法要求它只凭定期设备报告推断位置、不能直接读取真坐标；这个数据边界也需场景解释。不能把父亲直接等同敌方 Agent，也不能预设他已被 AGI 完全控制。
5. **RESET 是结构性冲突。**现行规则允许成功后仍整轮重启，维修状态与真实报告复原、双方保留记忆；长篇只有线性时间，没有物理回退技术。若每轮都是故事里的真实潜入，当前规则会与已发生的转送和维修记录冲突。它不能只靠一句台词补齐。

## 插入点与此前的实景关卡候选

最自然的接缝是长篇《十一 2042 早晨出门的人》的最后一句：哥哥指着记录里的转送口，问叔叔从哪边能到那里。**从这一刻开始写第一段可玩章节**，玩家的目标是弄清妹妹被送往何处，而非回到已经结束的转送现场。

此前提议把四区关卡设在**康复站旁、由联合体承包的专用转运通道维护侧区**，以修门机取得通路。原文已有专用通道、门禁应急状态和转送口，地点可以继续作为设施模型的现实对象；“偶然故障挡住线索”的任务理由与现实四次复位仍不充分。本轮允许更换物件、要求重启有世界内解释后，推荐采用下文的核验装置与维护行动预演候选，不将旧的门机桥接当作已定剧情。

这个位置比 2038 年灾害段更适合现行玩法：灾害段的行动者主要是父亲与医护，会换掉当前主角；比 2041 年社区水泵维修段更适合，是因为寻妹和对抗联合体的即时目标已经出现。也不要把关卡放进妹妹被带走的几分钟里，现行玩家角色当时不在场。

## 本轮客观评估

用户明确要求世界内解释后，仅将 RESET 当作游戏层重试的建议不再满足要求。前三个方向分别提供首章行动路线、哥哥的能力来源与调查主题，尚不足以构成三套完整架构。“本地交接核验装置”只解决目标物件用途，仍需解释重启和现实证据的关系。

原文中海普已看到“本人不同意”，仍未撤回指令。找到准确记录能够推进调查，不能自动终止转运。哥哥开场已经知道监护异议未能阻止转运；结尾只重复这一点，没有足够剧情增量。必须取得接收机构及可实际追查的联络线索。父亲的内部摘要仍不属于哥哥开场知识。

现有玩法直接支持观察、描述、有限协作、根据旧报告推断位置与重试学习。关灯、维修、撤离本身不能证明哥哥已经学会尊重妹妹。首章兑现一次寻人进展，人物转变留待后续与妹妹交流时继续展开。

## 按最少玩法改动收敛

| 决策 | 当前推荐 | 代价或条件 |
| --- | --- | --- |
| 谁组织模拟，四轮对手是谁 | 贾斯珀使用维护预演工具，系统 Agent 按站点巡检规则运行对抗实例 | 新增局部预演工具；不要求复制联合体完整 AGI，现实联合体不获知离线练习过程 |
| 如何从模拟得到现实剧情进展 | 原有结算页用简短叙述交代一次现实核验及其所得 | 预演不能生成妹妹真实去向；收回额外可操作现实尾声，不增加第五轮 |
| 核验、维护与通行权限的关系 | 本地机构保留指定案件核验与有限维护接口，联合体管理专用通道 | 新增共管权限边界；可调灯不等于可进全部区域或读取任意病例 |
| 助手协作与结局条件 | 保留描述、有限改设备、继续观察与四轮总评；按既有结算设计衔接剧情 | 不额外默认加入至少一轮或末轮成功的门槛；全败不能直接写成取证成功，不隐含求助次数的道德评价 |

不推荐新增“家属必须赢四轮潜入比赛才可查询”的制度：它把模拟成绩接到现实许可，却与医疗照护目的缺乏因果关系。意识副本与真实时间回退也不是已有材料的推论。

## 推荐提案：四轮预演与既有结算页

以下为供选择的完整构筑，尚未成为正史。

妹妹离站后，贾斯珀与沈芮继续办理异议、确认接收方。本地接待端只有摘要，详细交接凭据留在现场核验装置；应急管制尚未解除，常规调阅不能立即完成。哥哥提出承担现场部分，贾斯珀用平日维护训练工具与他先检验通路，沈芮准备指定案件的核验材料。正规处理继续进行，预演用于评估另一条行动路线；不要求哥哥是唯一有能力行动的人。

新增核心设定控制在两项：贾斯珀平日使用局部设施预演工具；康复站本地交接核验装置留存这次转运的详细接收凭据。预演模型根据维护资料描述房间、设备、操作条件，对抗 Agent 按站点巡检规则测试路线；不要求获得联合体完整模型副本。预演不含妹妹真实接收地点、临床档案或海普内部摘要，也不能宣称准确预测现实的一切行为。康复站本地机构与联合体共管的关系已有原文依据，具体有限权限仍需补写。

玩家仍扮演哥哥，四轮操纵的是训练界面中的行动角色，不新增意识上传。开场就告知当前是预演。训练程序掌握场景、负责验算与保存；对手测试实例只读批次设备报告；助手沿用现场接口，只读玩家描述与执行回执。个人助手的地图限制来自训练沿用真实部署权限，不能因模型已加载就把布局输入助手。

每轮执行“到场—停留恢复核验装置—产生准确操作报告—抵达出口”。模拟装置给出任务完成标记，不填入真实机构名字。操作报告指明设备和该分支时间，系统据此推断，玩家须考虑撤离窗口。关闭照明不会消除装置自己的操作报告。

四轮后仍进入原有总评界面。成功结算中的简短叙述交代：哥哥与贾斯珀随后参考已检验的路线，在现实站点重新确认现场、完成核验，带回接收凭据。界面展示接收机构、交接编号与下一步联络入口。不开新地图，不加可操作尾声、第五轮或文件核对小游戏。现实取证必须作为确实发生的后续事件写明，不能把模拟标记直接当成真实凭据，也不建立“练习成功保证现实成功”的世界规则。

四轮成绩继续累计、最后总评，剧情跟随结算结果呈现。此前“至少一轮成功”的建议不再作为默认剧情门槛，具体结算映射与原本待定的成绩规则一起处理。全败时人物继续正式联络，本次不能自动取得接收地点；避免为了固定结尾增加无条件成功。数值与判定留待同一套结算设计，不再叠加独立剧情考核。

叙事呈现限定在现有位置：开场交代妹妹已离站、需要查询接收方及当前正在预演；目标装置名称和操作回执体现核验用途；轮间短句说明对手改了配置；总评页给出对应现实结果。不开设额外剧情任务，不用长篇条款解释每一个计数。四轮与三次回退作为本次训练配置即可成立。

## 双重重启如何成立

| 机制 | 世界内含义 | 信息与状态边界 |
| --- | --- | --- |
| 局部回退，整场三次 | 哥哥调用训练会话的周期检查点 | 恢复模拟现场与有效报告；现实转运不变，机会与已结算成绩不恢复 |
| 初始轮加三次整轮重启 | 四轮压力测试，对手依据自身报告历史选择合法配置 | 成功仍继续测试，不表示现实再次丢失凭据或重复转运 |
| 双方记忆保留 | 哥哥记得练习，助手与测试实例的会话记忆保存在检查点之外 | 各自只保留原规则允许的信息；离线测试记忆不传给现实系统 |
| 撤销分支 | 留作历史训练日志 | 不冒充当前观察，更不能充当现实证据 |
| 对话和模型推理暂停 | 训练场景暂停 | 现实时间仍流逝，等待与尾声都计入整场体验目标 |
| 新增设备 | 模型启用预装备用设施或切换合法设备配置 | 对应可存在的现场设施，不解释为现实瞬间安装 |

四轮和三次回退是这次训练会话的配置，不必成为整个世界的技术定律。模型更新时间、场景可信程度与现实路线选择仍有不确定性，不能夸大为预测能力。

## 设备映射与第一轮优化

| 元素 | 推荐映射 | 保留的玩法性质 |
| --- | --- | --- |
| 电机 | 本地交接核验装置，现场恢复其本地读取接口 | 到场、停留、准确报告、撤离；不靠偶然坏门解释任务 |
| 摄像头 | 维护通道可见光占用摄像头 | 固定感知参数，可调朝向／区间；黑暗为未知，不新增红外或精确身份定位 |
| 灯 | 维护区工作照明 | 真正影响可见光观察，保留数量、时长、冷却；不只换状态灯颜色 |
| 机器人 | 固定范围的巡检／清洁设备 | 被动观察，不追逐、抓人或维修 |
| 联络点 | 本地现场维护接口 | 按点限次，助手少量改设备，离点不能继续操作 |
| 定位命中 | 测试实例提出检查范围，训练程序验算该尝试被截停 | 维持固定形状范围与周期；Agent 不能自行宣布命中 |

需要明确一个容易遗漏的信息通道：若系统实时知道正在使用哪台维护终端，就增加了现行规则外的定位信息。推荐规定本地维护链路不给定位 Agent 终端源地址，定位输入仍按获准设备报告组织；目标装置产生的准确操作报告照常保留。该隔离需写进共管设施的新设定。

优化后的现实因果是“妹妹转运—家属无法立即确认接收方—现场核验需要通过管制区—先做有限预演—一次真实操作取得下一站”。四轮内部是“观察—描述—助手有限调整—行动与上报—系统定位—回退或换配置—再次检验”。前者解释为何玩，后者解释如何玩；二者通过现实执行接合，不能让模拟文件代替真实凭据。

## 纸面验收与实际限制

- 开场能说明妹妹已经离站、目前在预演什么、之后要去哪里；不靠结尾反转告知“原来是模拟”。
- 移除妹妹的真实数据，四轮仍能运行；取得现实凭据前不能出现确定的接收地点。
- 成功后重启、双方记忆、局部回退用同一套训练机制解释，撤销分支不污染当前报告。
- 取得现实资料的权限来自指定案件与现场核验，不能由模拟胜负凭空授予；真实所得在原有结算页交代。
- 全败保留失败含义；成功尾声必须带来新的地点和联络入口。
- 角色的长期目标包含妹妹自己的意愿；本章不以求助次数或通关成绩给人物作道德评判。

以上为叙事与规则的纸面检查，没有可玩原型或试玩数据。保留预演意味着即时危险感较弱、现实行动只在结算中交代；这是优先保留玩法框架的取舍。原型应检查开场是否易懂、联络是否有策略价值、四轮是否产生变化，不能用增加剧情篇幅替代验证。
