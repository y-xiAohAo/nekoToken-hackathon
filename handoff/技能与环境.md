# 技能与环境

> 此页保留迁移背景。2026-11-27 起，日常开发使用 [跨平台检查](../CONTRIBUTING.md#本地检查)，不要求附带 `tools/`。本机 Godot 和模型复核见[赛前检查](赛前环境检查_2026-11-26.md)。

## 技能在哪里

`.agents/skills` 包含迁移时复制的 49 个技能目录；每个目录连同 references、scripts、资源和已有许可证一起保存。实际来源与文件数见 `skills_inventory.json`，来源路径是迁移快照，不是当前机器的依赖。原工程的编码纪律等单独保存在 `.kimi/skills`，避免科研专用技能误当游戏技能自动加载。

主要开发入口：`hackathon-spec`、`game-jam`、`prototype-fast`、`level-design`，以及各项 `godot-*`。`platformer` 是早期横版方案遗留，当前方案不含跳跃，暂不启用。中文润色用 `humanizer-zh`；文档用 `pdf`、`documents`、`presentations`、`spreadsheets`。

### 按当前项目的使用状态

| 状态 | 技能 | 说明 |
| --- | --- | --- |
| 当前开发 | `hackathon-spec`、`game-jam`、`prototype-fast`、`level-design`、`godot-2d-movement`、`godot-export`、`godot-gdscript`、`godot-gdscript-headless-testing`、`godot-nodes-scenes`、`godot-physics`、`godot-ui-control` | 方案到 Godot 原型的主路径；仅在对应任务出现时读取 |

| 可选工程协议 | `vibe-coding-harness`、`sdd-riper-one` | 用户明确要求相应流程时启用，复制存在不等于自动启用 |
| 迁移附带、暂不属于游戏主路径 | `deepscientist-*`、`nature-*`、`openai-docs`、`skill-creator`、`skill-installer`、`template-creator`、`create-statusline`、`excel-live-control`、`spreadsheets` | 保留以支持通用工作区任务；不作为游戏实现前提 |
| 历史能力 | `platformer` | 初始横版跳跃方向已被同层实时潜入方案替代 |

`excel-live-control` 与 `spreadsheets` 存在部分相同的说明文件，这是上游技能包的共享内容，不是本项目新增的两套规则；保留两个入口以区分实时 Excel 会话与普通表格文件。

可选的 `sdd-riper-one` 与 `vibe-coding-harness` 附完整源文件，原电脑绝对路径请按同名本地目录映射。没有因为复制文件就自动启用额外审批流程。

## 哪些已经随包携带

- Windows x64 Python 3.12核心与所选已安装包，含PDF、Word、图像API脚本常用依赖及pip；版本见锁文件。完整原始site-packages没有搬来。
- Poppler命令和依赖DLL，用于`pdftoppm`、`pdfinfo`。
- Node可执行文件，用于技能里的本地JavaScript工具；没有复制全套Node依赖生态。
- 当前工作区既有的图像CLI依赖仍在`tmp/imagegen/cli-deps`，属于原材料快照。
- 包内脚本提供校验、当前会话工具路径和可选用户级技能安装。

## 哪些需要参赛机准备

| 项目 | 当前状态与操作 |
| --- | --- |
| Godot | 本机已复核 Steam 版 4.2.2 与导出模板；团队版本待锁定，正式项目尚未创建。新机器自行准备同版本引擎与模板。 |
| Git | 新机器安装后克隆项目仓库；原父仓库没有本游戏的提交历史可搬。当前可见性见根目录 README。 |
| Agent客户端 | 安装并打开本目录；先确认能列出本地.skills并读取支持文件。若客户端不发现项目技能，可运行可选Install-UserSkills脚本复制到用户技能目录。 |
| 模型账户/API | 在参赛机配置；`.env.example`给出空字段，不携带密钥和CCSwitch账号配置。模型是否支持结构化工具调用需要真实检查。 |
| 中文字体 | 报告脚本使用Windows微软雅黑；自检检查msyh.ttc/msyhbd.ttc。不另行复制系统字体。 |
| 桌面插件与MCP | skills只包含说明与脚本；需要宿主客户端安装相应插件、连接服务并授权。复制技能不能重建图像模型、可视化服务、Live Excel会话或云端连接。 |

DeepScientist系列技能依赖其artifact/science服务及科学包。源文件随包，但本游戏不以其外部服务作为开发前提。文档插件中的操作标记、在线能力同样以实际客户端是否提供为准。

## 重建既有文档

原 `tmp/pdfs/` 的 v0.8 和个人介绍生成器已移动到 [archive/production](../archive/production/README.md)，依赖锁文件一并归档。它们会向旧目标写入，不直接作为当前文稿的生成入口；需要复现时，在独立工作区检出初始提交 `b903bb9` 并按历史路径准备依赖。历史文本和脚本字节不作批量替换。

当前维护脚本验证仓库内容、链接和脚本行为。Godot、图像模型、真实模型接口和桌面插件仍需各自实际验证，不能用仓库检查通过代替。
