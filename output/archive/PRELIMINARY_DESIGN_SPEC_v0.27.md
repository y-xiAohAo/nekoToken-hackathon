## 当前玩法工作基准（2026-11-14 侦测定位方向）

**最新决定：采用实时方案。** 玩家连续移动，灯、摄像头和机器人实时运行；设备由游戏程序持续检测，按固定周期批量上报，保留实际观察时间戳与当时检测区域。发现时间、上报时间、定位时间分开；不采用只在固定上报瞬间检测的规则。具体检测频率、上报间隔、批次数与报告压缩方式待定。

当前见[侦测定位机制基准 v0.18](../../侦测定位_机制草案.md)。已确定实时感知、周期上报、互斥的系统推理与联络暂停、二值照明及确定性感知；采用同层方格，取消高低差。个人助手完全看不到地图，依靠玩家描述建立设备代号与空间对应，只在联络点会话，回退后仍需到达可用联络点。系统定位猜错后提交设施调整并允许新增一处，类型、位置、上限与具体新增生效细节待定；助手改动在联络结束后提交。两个阶段互斥，不存在双方并发下令的竞态。“有人”报告对应有限区域，系统结合时间戳与多设备情报推理。双方对同一设施采用后发有效指令相互覆盖，未改写的设置继续保持；灯关闭时长、冷却与RESET等硬规则继续生效。助手每次联络最多做1–2个改动；每个联络点在每个完整RESET轮次只能会话一次，多个联络点分别计算；局部回退恢复快照中的已用／未用状态，整轮RESET重新开放各点。系统可调更多设施。助手不能改写情报真实性，可影响未来新鲜情报时效。摄像头固定距离、瞬时夹角和首版速度，优先调整朝向与区间。双重RESET为系统3次整轮复测形成4轮，玩家整场3次单定位周期回退；三方保留获准记忆。单轮修复电机后抵达出口成功，维修也产生上报；评分初期暂缓。具体可改字段、会话内通信限制及新增设施细则待定；[联络点协作候选](../../archive/concepts/个人Agent_联络点协作候选.md)含历史提案，以本基准为准。V3只保留美术参考。

- **已明确：装置不自主决策**。灯、摄像头和机器人是受 Agent 调控的简单装置。机器人仅在系统 Agent 指定范围内巡逻，视野固定；不自动追逐、检修或决定玩家失败。
- **已明确：二值照明及关闭约束**。每格只有亮／暗，至少一盏开启且覆盖的灯使其为亮，多灯叠加不增加亮度。灯不能永久关闭，限制同时关闭数量、单次关闭时长，并存在冷却。具体覆盖、数值和冷却起算时机待定。
- **已明确：三种观测结果**。装置返回“有人／无人／无法确定”。“有人”对应一片有限区域，不能过大或直接交付真实玩家格；系统结合多个设备与原始时间戳推理。不能把无法观测误报成无人，不同时间的目击也不能直接作静态交集；具体区域与编码待定。
- **已明确：定位与回退补救**。系统 Agent 提交方格坐标范围，命中暂停时玩家位置后，可选择消耗局部回退；放弃或次数用尽才结算本轮失败。形状固定，具体选正方形还是近似圆形及范围大小待定；传感器观测本身不直接触发失败。
- **已明确：实时感知、周期上报与定位**。设备持续检测，发现时间可发生在任意游戏时刻；每隔 Δt 统一上报，保留原观察时间戳及当时检测区域。每 N 个上报批次执行一次定位，T = N × Δt。N不按目击事件数或设备报告条数计数，没有目击的窗口同样推进。T为游戏内行动时间，不包含网络等待；Δt、N待定。定位形状已固定，具体形状与范围大小待定。
- **已明确：推理期间暂停**。第 N 个上报批次完成后冻结游戏时间、玩家、机器人和装置；灯时长、冷却、新增感知与上报同时停止。系统 Agent 完成一次定位，程序按暂停位置结算；未命中后提交调整，再开始下一周期。系统推理／结算与联络互斥；助手改动在联络结束后提交。
- **已明确：系统调度**。系统行动中的设施调整仅在定位猜错后提交，随后恢复行动；不在玩家联络期间调度。初始配置与RESET恢复沿用各自规则。
- **新增方向：未命中后扩大设施覆盖**。系统一次定位猜错后，除调整现有设施外，允许新增一处设施。新增类型、合法位置、上限、生效和RESET恢复规则待定；预置槽位、优先新增灯是助手建议。按现有感知规则，新增摄像头本身不减少暗区。压力随行动时间推进，对话及推理暂停不推进压力。
- **已明确：联络点对话暂停**。玩家在指定联络点开始会话后，玩家、机器人、摄像头、灯、感知、上报和所有游戏内计时冻结；会话结束后提交通过校验的助手改动，再从冻结状态恢复，不要求先离开联络点。未改动部分接续原轨迹，已改动部分接续新安排，不补算暂停期间的移动或冷却。系统不在此阶段推理或调度。具体助手可改字段、对话轮数及内容量限制待定；3轮、每条约200字等仅为候选，详见机制基准第2.4节。
- **已明确：玩家观察、助手无地图**。灯覆盖、摄像头扫描和机器人位置让玩家看清；个人助手完全看不到地图分布，依靠玩家描述建立代号、位置和范围对应，并理解路线目标。可保留自己从对话整理的旧认知；接口不自动补成当前全图。非空间可读字段及具体操作权限继续讨论。
- **已明确：确定性感知与摄像头参数方向**。设备在当前视野内、无遮挡且格子亮时可观察，由程序确定性判定，保留有人／无人／无法确定的报告；不增加数值亮度与置信度系统。摄像头区分瞬时视野夹角和摆动扫描范围，固定前者及距离，优先允许调整扫描朝向与区间，速度先固定，详见机制基准第4.2节。
- **双方指令覆盖**。同一设施、同一控制项采用最后一条有效指令；系统和助手可相互覆盖，无固定身份优先级。未改动的设置跨周期继续，不在系统调度时自动恢复旧配置。灯时长、冷却及RESET等规则仍可终止或限制效果。个人助手每次联络最多提交1–2个改动；每个联络点在每个完整RESET轮次只能会话一次，多个联络点分别计算。系统可调整更多设施。系统猜错后调度，助手联络结束后提交，两阶段互斥，先后由游戏流程确定，无需并发仲裁。助手不能修改历史报告、结果或时间戳；首版优先考虑灯状态和摄像头朝向／扫描区间，机器人权限尚未确认。

- **视觉与操作延续**。保留赛博像素三渲二、高俯角2.5D、一屏与无跳跃；地形改为同层方格，无楼梯、高台与高低差。玩家连续实时移动，方格用于空间判定；连续位置如何归格与斜向移动规则待定。装置、墙、灯区和联络点需重排；V3不再作为当前空间方案。
- **已明确：任务型单轮目标**。加入电机物件，玩家修复电机后抵达出口即成功，维修也产生上报事件。电机数量、具体交互、事件粒度和出口可通行反馈待细化，详见机制基准第6.3节。
- **待细化的关卡内容**。联络点、电机和出口的布局、藏身／墙体遮挡规则、RESET合法初始化配置与具体快照字段需与定位机制衔接；旧稿三份线路修补配置不自动沿用。电机进度随现场快照恢复，跨RESET的维修经验随三方记忆保留。
- **已明确：多轮失败处理**。本轮最终记为失败后仍继续下一轮，最后按总成绩评价；首版4轮，评级细则待定。
- **已明确：双重RESET**。系统3次轮间整轮复测与初始轮构成4轮；玩家整场共享3次局部回退，定位命中后可退回当前定位行动周期起点。现场、有效报告和各联络点使用标记恢复快照，次数账本及已结算成绩不恢复。快照中未用的点可重新会话，已用的点仍然已用；整轮RESET重新开放各点。具体时长与会话内通信限制待定，详见机制基准第6.2节。
- **已明确：三方记忆保留**。玩家、个人助手、系统Agent在局部回退及整轮RESET后均保留各自获准的历史；系统不能清除个人助手记忆。撤销分支必须标为历史，旧地图配置及旧目击不能直接当作当前事实；保留记忆不延长已重置干预的效力，也不新增读取权限。
- **已明确：回退后的会话限制**。局部回退不开放即时对话，仍须到达快照状态下可用的联络点讨论；不清除旧对话，也不授予远程追加命令权限。若恢复起点本就在可用联络点，沿用正常联络规则，无须额外离点再返回。旧会话保留为历史，不自动重交被撤销命令。
- **评分暂缓细化**。用户选择后续按时间、消耗额度等评价成绩；初期仅记录方向，不展开权重、优秀阈值或具体扣分。优先完成联络—维修—定位／回退—撤离的一轮流程。
- **依赖代价方向与诚实边界**。当前限制为每点每轮一次会话、每次1–2个改动；各点分别计算，不另设永久全局干预消耗池。一次会话将改动用于可手操避开的设备，可能失去对同一行动段关键设施的干预机会；离点后也无法随时追加命令。局部回退可恢复使用前状态，但消耗整场有限的3次回退。通信限制与设备改动分别表达，耗尽不直接判负；这种取舍是否有趣仍需原型验证，不能声称依赖必然失败。玩家描述、助手规划与手操的协作价值尚无试玩或平衡结论。
- **保留约束**。Godot、两人72小时预算、约10分钟目标体验、玩家侧 skill 与受控接口；当前仍是预赛方案讨论。

- 一张玩法循环框图，说明玩家行动、设备上报、系统推理、联络对话、助手改动和 RESET 的关系；

## 二、方案成果展示【提交时必填】

### 1. 赛题理解

我们将「重启」理解为**重新分配记忆与控制权**：死亡会使关卡回到起点，却不会让玩家、玩家侧 Agent 和世界管理员回到完全相同的认知状态。每次重启，双方都会依据上一轮的记录改变判断；下一轮因此不是机械重复。

目标受众是喜欢短时动作解谜、时间循环和 AI 互动的玩家。我们针对的体验痛点是：传统重试常只要求记住固定陷阱，生成式 AI NPC 又常停留在聊天，玩家的行动没有明确、可检验的后果。我们希望让**手操、Agent 协作与对手适应**共同决定下一轮。

### 2. 具体方案

#### 2.1 核心设定

玩家困在一个由「世界管理员」管理的单屏测试室，目标是在有限时间内抵达出口。世界管理员是游戏内的 Agent NPC，能接收玩家移动、死亡、求助、干预等**结构化事件记录**，但每次只可在规则允许的时点调整有限的关卡参数。玩家侧 Agent 是随游戏提供 skill 接入方式的独立助手，拥有玩家无法直接使用的「读取重启档案」与「提交一次世界干预」权限。玩家本人掌管即时移动、跳跃、试探和最终路线选择。

这里的「读取全部操作」指游戏可记录全部操作；给模型的输入是压缩后的关键事件和状态，不要求模型逐帧处理操作。世界变化须受程序验证，不能制造无解关卡或临场作弊。

#### 2.2 三个核心设计点

**A. 对抗式记忆重启。** 玩家死亡时形成一份本轮事件日志。玩家侧 Agent 从中提取一条可保留线索；世界管理员也保留一项关于玩家习惯的判断。关卡重置后，双方各带着不完整但有用的信息继续。这使下一次尝试既有学习收益，也有被针对的风险。

**B. Agent 专属干预。** 玩家侧 Agent 可读取玩家界面看不到的死亡归因/管理员判断，并在重启前提交一次受限干预，例如锁定一个平台位置或改写一道门的开放条件。玩家不能通过手操直接调用此权限。干预为玩家创造机会，但不替玩家完成移动或通关。**具体干预对象需在下一轮讨论中选定一种作为主机制。**

**C. 看得见的适应与反制。** 世界管理员观察玩家是否反复采纳助手建议或使用同一种干预，并在下一轮从有限的合法变更中选择一个反制。玩家能从场景变化与管理员反馈中识别其判断，也可把助手建议作为诱饵，亲自走不同路线。失败不由「使用 Agent 次数」直接判定，而来自可理解、可反制的世界变化。

#### 2.3 单局体验流程（目标 3–10 分钟）

1. **初探（约 1 分钟）**：玩家在单屏房间学习移动、跳跃和出口目标，第一次遭遇陷阱或失败。
2. **第一次重启（约 1 分钟）**：个人 Agent 解释死亡记录，提出一次专属干预；世界管理员给出对玩家行为的可感知回应。
3. **第二轮博弈（约 2–3 分钟）**：玩家借助干预推进，发现世界管理员会针对已暴露的习惯调整规则。
4. **最终尝试（约 1–3 分钟）**：玩家结合 Agent 给的信息与自己的手操，选择按建议通关，或故意误导管理员后另辟路径。
5. **结尾（约 30 秒）**：显示本次重启记录、管理员如何判断玩家、玩家如何利用或打破该判断；鼓励重玩另一种策略。

这是目标体验脚本，并非承诺每位玩家都恰好经历同样次数的死亡。原型至少应支持两种有意义的通过方式。

#### 2.4 AI 技术路径与创作流程

- 采用 Godot 开发单屏 2D 游戏；游戏程序处理移动、碰撞、死亡、状态保存与规则合法性检查，保证操作即时反馈。脚本语言暂按 GDScript 规划。
- 事件层把关键操作整理为简短日志：如死亡位置、尝试路线、求助内容、使用的干预和通关结果。
- 世界管理员 Agent 读取事件摘要，从**预设合法变更**中选择一项，附上符合角色设定的解释；程序验证后才应用。
- 玩家侧 Agent 通过随游戏提供的 skill 说明与受控接口读取档案、提交一次干预；skill 负责说明用法，实际权限由游戏接口授予。
- 决赛原型计划随游戏交付**玩家侧 Agent skill 与受控接口**，这是方案的核心机制。为便于评审直接体验，可另外提供使用相同权限与接口的内置演示助手；两种入口不应形成不同玩法规则。
- 模型不可用或超时时，游戏使用预设决策继续运行；不让一次网络调用阻断关卡。

### 3. 方案价值与预期效果

**玩家体验**：失败会产生新的可用情报，也会让世界管理员形成新的判断，促使玩家主动尝试不同的行动和求助方式。玩家侧 Agent 提供确实无法靠手操完成的能力，但最终仍要靠玩家操作和判断完成关卡。

**AI 应用价值**：Agent 的输出落到具体、可验证的规则变化，不仅生成对白。可重玩性来自玩家策略、双方记忆与有限规则组合，而不是无限随机内容。这里的体验提升是设计假设，预赛不声称已经取得量化效果。

**72 小时可演示范围**：一个单屏关卡、一个世界管理员、一个玩家侧助手、少量合法规则变化、一次专属干预、2–3 次清楚的重启反馈、至少两条通过路径；在此范围内形成可独立试玩的 3–10 分钟原型。

### 4. 方案优势与创新点

1. **双 Agent 的不对称关系**：一方帮助玩家获取隐藏信息并干预世界，一方根据同一轮行动学习玩家习惯；玩家在两者之间做决定。
2. **重启有代价也有收益**：玩家得到线索，世界管理员得到行为画像；每次重启都改变下一轮的策略空间。
3. **玩家手操仍是核心**：Agent 不能代打；它提供情报与一次有限干预，玩家负责执行、试探和误导。
4. **AI 决策可展示、可复现**：界面向玩家展示关键观察、规则变更及其结果；合法动作受游戏程序约束，适合短时路演。
