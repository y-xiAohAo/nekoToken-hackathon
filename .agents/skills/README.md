# 工作区技能目录说明

这里保存迁移时携带的技能副本，供参赛机离线恢复和按需读取。它不是玩家技能，也不代表宿主客户端的插件、MCP、模型或账号权限已经可用。

## 项目主路径

- 方案与原型：`hackathon-spec`、`game-jam`、`prototype-fast`、`level-design`
- Godot：`godot-2d-movement`、`godot-export`、`godot-gdscript`、`godot-gdscript-headless-testing`、`godot-nodes-scenes`、`godot-physics`、`godot-ui-control`
- 文档与素材：`humanizer-zh`、`pdf`、`documents`、`presentations`、`imagegen`、`visualize`
- 工程协议：`vibe-coding-harness`、`sdd-riper-one`（仅按用户明确要求启用）

## 暂不进入游戏主路径

`platformer` 属于已取消的横版跳跃方向；`deepscientist-*`、`nature-*`、`openai-docs`、`skill-creator`、`skill-installer`、`template-creator`、`create-statusline`、`excel-live-control`、`spreadsheets` 是通用或原迁移附带能力。它们保留在包内以支持其他工作，不参与当前游戏设计。

`excel-live-control` 与 `spreadsheets` 中的重复说明来自上游技能包的共享文件，两个入口分别对应实时 Excel 会话和普通表格文件，不合并其目录。

当前副本数量为 49 个。用户级安装结果以目标机的实际技能目录和客户端发现结果为准；只复制 `SKILL.md` 不会重建外部服务。
